## Return on AI（ROAI）とは

Return on AI とは、AIへの投資額ではなく、**AIが経営に返したもの**で成果を測る指標。
株式会社COREが提唱し、診断・設計・開発・運用のすべての工程で一貫して使っている。
AI投資は目的ではなく、売上・コスト・時間・リスク・新しい価値のいずれかを返して初めて成果になる、という立場を取る。

CORE ROAI MODEL は、AIが返すものを5つに分類する。

| # | Return | 何を増やす／減らすか | 代表的な測定指標 |
|---|--------|------------------|----------------|
| 01 | GROW | 売上・利益・顧客価値を増やす | 売上成長、商談→受注率、顧客LTV、営業1人あたりの生産性 |
| 02 | SAVE | コスト・工数を減らす | 人件費（時間換算）、外注費、管理部門コスト、手作業の時間 |
| 03 | ACCELERATE | 企業の速度を上げる | 意思決定までの時間、承認・稟議の日数、初回返答時間、提案作成の時間 |
| 04 | PROTECT | 損失・リスクを減らす | 期待損失（発生確率×影響額）、人的ミス件数、コンプライアンス違反、品質不良 |
| 05 | CREATE | 新しい価値を生む | 新規売上、新サービス数、顧客体験の変化、新しい事業モデル |

詳細: https://www.core-ai.jp/return-on-ai

## 進め方（一般的なAIベンダーとの違い）

一般的なAI開発会社は「何を作りますか」から始める。COREは「経営として何を達成しますか」から入る。

CORE の順序: 経営目標 → ベースライン測定 → KPI設定 → ROAIシミュレーション → 業務再設計 → 開発 → 導入 → 計測 → 改善 → 拡大。
納品はゴールではなく、計測の始まりと位置づけている（Build, Measure and Evolve）。

## よくある質問

**Q. 株式会社COREは何をする会社ですか。**
A. 企業をAI前提で再設計する AI Transformation Company です。AIツールを納品して終わりにせず、経営目標から逆算して業務・組織・システムを設計し直し、AI投資が返した成果（Return on AI）を計測するところまでを担当します。

**Q. Return on AI（ROAI）とは何ですか。**
A. AIへの投資額ではなく、AIが返した経営成果で投資を評価する指標です。売上（GROW）、コスト削減（SAVE）、速度（ACCELERATE）、損失回避（PROTECT）、新しい価値（CREATE）の5つのReturnで測ります。
