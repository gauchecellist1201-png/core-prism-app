Return on AI（ROAI）とは

Return on AI とは、AIへの投資額ではなく、AIが返した経営成果で投資を評価する指標です。 株式会社COREが提唱し、診断・設計・開発・運用のすべての工程で一貫して使っています。 AI投資は目的ではなく、売上・コスト・時間・リスク・新しい価値のいずれかを返して初めて成果になる、という立場を取ります。

CORE ROAI MODEL — AIが返すものを5つで測る

  1. GROW（売上・利益・顧客価値を増やす）：売上成長、商談→受注率、顧客LTV、営業1人あたりの生産性。
  2. SAVE（コスト・工数を減らす）：人件費（時間換算）、外注費、管理部門コスト、手作業の時間。
  3. ACCELERATE（企業の速度を上げる）：意思決定までの時間、承認・稟議の日数、顧客への初回返答時間、提案作成の時間。
  4. PROTECT（損失・リスクを減らす）：期待損失（発生確率×影響額）、人的ミス件数、コンプライアンス違反、品質不良。
  5. CREATE（新しい価値を生む）：新規売上、新サービスの数、顧客体験の変化、新しい事業モデル。

Return on AI の考え方をすべて読む

AIから考えない。経営成果から逆算する。

一般的なAI会社は「何を作りますか」から始めます。COREは「経営として何を達成しますか」から入ります。

CORE の順序：経営目標 → ベースライン測定 → KPI設定 → ROAIシミュレーション → 業務再設計 → 開発 → 導入 → 計測 → 改善 → 拡大。 納品はゴールではなく、計測の始まりです（Build, Measure and Evolve）。
